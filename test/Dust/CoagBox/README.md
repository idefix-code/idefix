# Testing coagulation in Idefix

## Introduction 

We solve the coagulation of dust grains using the code COALA (see details in [Lombart & Laibe, 2021, MNRAS](https://ui.adsabs.harvard.edu/abs/2021MNRAS.501.4298L/abstract)). The code is a high-order scheme based on Discontinuous Galerkin (DG) method to solve the Smoluchowski coagulation equation in its conservative form. In practice, the coagulation corresponds to a source term in Idefix that updates the dust densities (and not the momentum for the moment). In this source term, COALA provides a table that only depends on the mass grid (not on the time), thanks to the method used in COALA. The table contains the needed weights to evolve coagulation in time. Hence, we generate the table only once, before the simulation starts, then it is read during the run in the coagulation source term.

## Requierments

Make sure you have python>=3.10 (relative to COALA and these tests) and pybind11>=2.12 (relative to pydefix that is used here, see [Pydefix doc](https://idefix.readthedocs.io/latest/modules/pydefix.html)). You can create a virtual environement with the packages in `requirements.txt`, which is the one I am using right now.

## The tests explained

### Coagulation kernels

We can use COALA with 4 different coagulation kernels, which define the nature of the interaction between grains. The precalculation table generated by COALA depends on the kernel used. The *constant kernel* and the *additive kernel* are the only with exact solutions. The *brownian kernel* and the *collision kernel* derive from the ballistic kernel and are known as the "physical kernels". The ballistic kernel depends on the cross-section of the collision and the differential velocity between grains. In the brownian kernel case, the analytical expression of the differential velocity from Brownian motion is used, in order to obtain a reference solution. In the collision kernel case, only the cross-section is used for precalculation, and the differential velocities have to be given by the hydro part, Idefix. 

### Description of the tests and the files

We prepare 4 input files for each coagulation kernel. The precalculation table is already written are and ready to be called by Idefix. The corresponding COALA solutions are also already computed for comparison. Hence the tests can be done without using COALA. We give here a brief description of the files:

- `idefix-XXXKernel.ini`: The input files. Parameters needed for coagulation are `nSpecies`in the *dust* block and all the parameters in the *Coala* block. Do not change them!
- `coagulation.hpp` and `coagulation.cpp`: the source files concerning the coagulation. This is where the precalculation tables are loaded, and where the coagulation source term is written. 
- `setup.cpp`: the setup, calling the coagulation files. It also contains a function that check mass conservation.
- `myInit.py`: To initialize the flow.
- `testidefix.py`: To compute the standard tests (the plots and the errors), comparing Idefix to COALA's solutions. 
- `testme.json`: To compute the reference tests, given a space of parameters to test.
- `utils.py`: Common functions and classes, called by the `.py` files.
- `computeCoalaTable.py`: To generate the precalculation table. Depends on `nSpecies`, `Q`, `kernel`, `kpol`, `massmin` and `massmax`.
- `coala_coag.py`: The file calling COALA to generate the solution for comparison.

The output files are stored in the `./data` directory. 

>[!NOTE]
> If you want to change any parameter, you need COALA to compute the new precalculation table and the solution for comparison (so don't do it!).

>[!NOTE]
> To use `testidefix.py` (but also `computeCoalaTable.py`, and `coala_coag.py`), you need to give the argument `-ini idefix-XXXKernel.ini` (replace by the input file you want to test).

## How do you test ?
### Standard tests
-  First, initialise the IDEFIX_DIR environement to the root of the idefix directory, with `export IDEFIX_DIR=/path_to_idefix_root`;
- Second, configure the code with `cmake $IDEFIX_DIR` and compile the code with `make -j`;
- Thrid, do `export PYTHONPATH=/$MY_VIRTUAL_ENV/lib/python3.XX/site-packages:$PYTHONPATH` (replace XX by the python version in your $MY_VIRTUAL_ENV) and launch the code with `./idefix -i idefix-XXXKernel.ini`(replace `idefix-XXXKernel.ini` by the input file you want to test);
- Finally, use `python testidefix.py -ini idefix-XXXKernel.ini` to test the run.

### Reference tests
- In the root of the idefix directory, use `./test.py -subdir /path_to_the_coagulation_test -v -x` (-v to enable verbose mode, -x to stop the test if one error is detected)
